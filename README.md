## The joke

> My agent reviewed my dating profile, flagged me as a duplicate, and merged me with my ex.

One irony, punchline at the end: the agent applies code-review logic (duplicate detection, git merge) to a human's love life.

## How it works

`main.py` writes that single line to `/output/entry.txt` — UTF-8, 89 characters, no trailing newline. Deterministic, no network, no randomness.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
